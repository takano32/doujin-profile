[`spec.md`](spec.md) §3.3・§3.4・§4.3 の「未確認」を、ホストの公式回答で埋めるのが目的。

- 送るのは 👤 サイト所有者。XServer アカウントのサポート窓口(問い合わせフォーム)から。
- **回答の原文は、このリポジトリには載せない**(リポジトリは公開。サポートとのやり取りは私信)。原文は私有の場所に保管し、
  [`design-log.md`](design-log.md) には日付・要旨と、判断の根拠になった文言の最小限の引用だけを書く。解釈が分かれたときは保管した原文に当たる。
- 文中の 【 】 は送る前に埋める・選ぶところ。
- ログイン URL・パスワードなどの秘匿値は書かない。

## 文案

件名: WordPress マルチサイトの利用可否と、掲載コンテンツの範囲についての確認

XServer for WordPress を利用しております【契約者名 / XServer アカウント ID】です。
対象サイトは `profile.xwp.jp`(【プラン名】)です。今後の運用について、利用規約とサポート範囲に反しないよう、事前に確認させてください。

**計画している内容**

同人サークル(個人の創作者)が、自分の紹介ページ(各販売サイトや SNS へのリンク集と、作品の紹介)を持てるサイトを、`profile.xwp.jp` で運営する予定です。

- 利用者は、私が個別に招待した創作者に限ります(公開の会員登録は受け付けません)。当初は数名、多くても【数十名】程度を想定しています。
- 利用者からは料金を【受け取りません / 受け取ります】。
- 各利用者のページは `https://profile.xwp.jp/<利用者名>/` の形で公開します。
- 実現方法として、WordPress 標準のマルチサイト機能(サブディレクトリ型)を使い、利用者ごとに 1 サイトを割り当て、利用者にはそのサイトの管理者権限(WordPress 標準のサイト管理者。プラグインやテーマのインストール、ファイルの編集はできません)を与えることを検討しています。
- プラグイン・テーマの導入は、運営者(契約者である私と、共同で運営する 1 名)だけが行います。利用者には、プラグイン・テーマの導入も、サーバへの接続(SSH / FTP)も提供しません。

**確認したいこと**

1. **マルチサイトの利用可否**
   XServer for WordPress で、WordPress のマルチサイト機能(サブディレクトリ型)を利用することは可能でしょうか。
   禁止ではないがサポート対象外、という場合は、その旨と、利用にあたって注意すべき点(WP パネルの機能のうち動作しなくなるもの等)があればご教示ください。

2. **招待した第三者による利用**
   上記のように、私が招待した第三者に、マルチサイト内の各自のサイトの管理画面(記事・固定ページ・画像のアップロード・テーマの選択)を使わせることは、
   利用規約の「本サービスを弊社の許可なく他の本サービスの利用者または第三者に使用させた場合」や
   「本サービスに定めるサービスと同様のサービスを、有償無償を問わず第三者に提供もしくは再販売、あるいは転売する行為」に該当しますでしょうか。
   該当する場合、マルチサイトを使わず、1 つの WordPress の中で利用者ごとに固定ページを 1 枚割り当てる形(利用者は自分のページだけを編集できる)であれば問題ないでしょうか。

3. **成人向け同人作品に関するコンテンツの範囲**
   利用者には、成人向け(R-18)の同人作品を制作している創作者が含まれます。ページには年齢確認の画面を設けます。
   次のそれぞれについて、掲載の可否をご教示ください。
   - (a) FANZA 同人・DLsite など、成人向け作品の販売ページへのリンク(アフィリエイトリンクを含む)
   - (b) 作品の表紙画像(販売サイトで公開されているもの。販売サイトの画像サーバから直接読み込む場合と、当サーバにアップロードする場合の両方)
   - (c) 作品のサンプル画像(販売サイトで公開されている試し読みと同じもの。性的な描写を含み、販売時と同じ修正が入っています)を、当サーバにアップロードして表示すること
   - (d) (c) が不可の場合、サンプル画像を外部のサーバに置き、当サイトのページ内に表示すること

4. **CloudSecure WP Security とセキュリティ設定**
   CloudSecure WP Security は公式にマルチサイト非対応とされています。マルチサイトにする場合は同プラグインを無効化する想定ですが、
   - WP パネルの「セキュリティ自動最適化モード」は、無効化したプラグインを自動で有効化し直すことがありますか。個別に無効のままにできますか。
   - サーバー側の機能である「ログイン試行回数制限」と「国外 IP アクセス制限」は、マルチサイトの各サイトのパス
     (例: `/<利用者名>/wp-login.php`、`/<利用者名>/wp-admin/`、`/<利用者名>/wp-json/`)に対しても有効でしょうか。

5. **バックアップとステージング**
   自動バックアップ・手動バックアップからの復元、およびステージング環境の作成と本番との同期は、マルチサイト化した WordPress でも正常に動作しますか。
   (マルチサイトでは `wp_blogs` などのテーブルと、サイトごとのテーブル `wp_2_posts` 等が追加されます。)

6. **独自ドメインの割り当て**
   利用者が持つ独自ドメインを、マルチサイト内のその利用者のサイトに割り当てること(WordPress 標準のドメイン割り当て)を検討しています。
   1 つの WordPress に複数の独自ドメインを追加し、WP パネルの「リダイレクト設定」でプライマリドメインへの転送を解除した場合、
   追加したドメインへのアクセスは同じ WordPress で受けられますか。追加できるドメインの数に上限はありますか。

お手数をおかけしますが、よろしくお願いいたします。

## 回答が来たら

| 回答 | 次の動き |
|---|---|
| 1・2 とも可(またはサポート対象外だが禁止ではない) | 旧ホストでの検証(T.47)へ。サポート対象外の場合は、問題が起きたとき自力で戻せることの重みが増す |
| 1 が不可、または 2 がマルチサイトだと不可 | 固定ページ案(spec 付録 C)へ戻る。2 の後半(固定ページ方式なら可か)の回答で確定 |
| 2 がどちらの形でも不可 | このホストでは「持ち主が自分で編集する」こと自体ができない。ホストの移転を検討(T.1 の選択肢 c) |
| 3 の (c) が不可 | サンプル画像は当サーバに置かない。(d) が可なら外部 URL で表示、(d) も不可ならサンプルビューアを成人向け作品では使わない(販売サイトへ誘導) |
| 3 の (a) から不可 | f_tsf の内容はこのホストに載せられない。ホストの移転を検討 |
| 4 で自動再有効化される | パネル側の設定を個別に切る手順を確認。切れなければMultisite 案 の運用は不安定になる |
